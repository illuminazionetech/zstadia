# Getting help

1. Run `zstadia doctor`. It checks every step and says which one fails.
2. Read [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) for the fix that matches.
3. Still stuck? Ask in [Discussions, Q&A](https://github.com/illuminazionetech/zstadia/discussions/categories/q-a). Include the output of `zstadia doctor`, with your home folder path replaced by `~`.

Found a bug? Open a [bug report](https://github.com/illuminazionetech/zstadia/issues/new?template=bug_report.yml).
Tried a game? Share it in a [game report](https://github.com/illuminazionetech/zstadia/issues/new?template=game_report.yml), whatever the result.
Security problem? Report it privately, as described in [SECURITY.md](SECURITY.md).
